# Tonino рядом с другим приложением на VPS

Комплект `compose.shared.yaml` использует существующий Caddy. Он не занимает
повторно порты 80/443 и не публикует API 8080. База и секреты Tonino отдельные.
У relay и Caddy общая выделенная Docker-сеть `tonino_proxy`; остальные приложения
и базы данных в эту сеть не добавляются.

Для первого теста можно использовать публичный IPv4 в адресе HTTPS. В этом случае
Caddy должен поддерживать ACME Profiles. Созданный `Caddyfile.shared` явно запрашивает
публичный сертификат Let's Encrypt с профилем `shortlived`. Caddy автоматически
обновляет его; самоподписанный сертификат и отключение проверки TLS не используются.
Справка: https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability/
и https://caddyserver.com/docs/caddyfile/directives/tls#issuers.

1. Создать приватную конфигурацию в новой копии исходников:
   `python3 deploy/configure.py ПУБЛИЧНЫЙ_IP ПУБЛИЧНЫЙ_IP --shared-proxy`.
   Для домена вместо первого аргумента использовать его DNS-имя.
2. Создать сеть `docker network create tonino_proxy`, подключить существующий
   контейнер Caddy к ней. Добавить эту внешнюю сеть также в постоянный Compose
   Caddy, чтобы она сохранялась при его пересоздании.
3. Запустить `docker compose -f deploy/compose.shared.yaml --env-file deploy/.env up -d --build`.
4. Поместить `Caddyfile.shared` в постоянное хранилище Caddy и добавить импорт
   в его основной Caddyfile. Сохранить резервную копию исходного файла. Сначала
   выполнить `caddy validate`, затем `caddy reload`, сохраняя работающий ingress.
5. Проверить HTTPS `/healthz`, отказ регистрации без кода, доступность прежнего
   приложения и TURN с внешней машины. В firewall провайдера разрешить TURN
   3478/TCP+UDP и 49160–49200/UDP. Docker публикует именно эти порты.

Для телефона адрес имеет вид `https://ПУБЛИЧНЫЙ_IP`. Закрытый код подключения
остаётся в `deploy/.env`. Он общий для закрытой тестовой группы; в APK его нет.
Переход на другой адрес пока требует нового профиля, поэтому выбранный адрес
нужно сохранять в течение этого теста.
