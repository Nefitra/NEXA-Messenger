8 серверных, 3 UI. Дополнительно прошёл один живой тест двух криптографических

Дополнительно выполнены перечисленные проверки сборки и пакета.

Проверены отбрасывание повреждённого шифротекста, подмена публичного ключа и
внешнего ID, повтор сообщения, одновременное начало двух сессий, сообщения
не по порядку, восстановление ratchet после перезапуска и отказ записи на диск.
Проверено, что удалённые одноразовые ключи не восстанавливают первую сессию
из более позднего состояния без её ratchet-записи.

Серверные проверки используют синтетические данные; отдельный интеграционный
тест выполняет настоящее шифрование libsignal и обмен через реальный relay.
Рендеры экранов регистрации и пустого списка чатов просмотрены визуально.

## Развёртывание VPS — 13 ноября 2026 года

- Relay работает в отдельном контейнере, SQLite и приватная конфигурация отдельные.
- Используется существующий Caddy; входной API-порт 8080 наружу не опубликован.
- Выдан публичный IP-сертификат Let's Encrypt с профилем `shortlived`.
  Автоматическое обновление выполняет Caddy. Отключения проверки TLS нет.
- При регистрации без закрытого кода получен HTTP 403.
- Аутентифицированный TURN по UDP и TCP передал по 10 из 10 тестовых пакетов.
- Внешняя машина проверила HTTPS, STUN/UDP и отказ TURN Allocate без авторизации
  по UDP и TCP. Проверка выполнена повторно после завершения размещения APK.
- APK скачан с VPS внешней машиной; SHA-256 совпал с указанным выше.
- Временный канал загрузки APK удалён. Два технических профиля живого теста
  удалены по точным UUID; реальных пользовательских профилей на момент проверки нет.
- Работающий сайт на том же VPS сохранил исправную БД и API; его приложение
  и база не перезапускались. Конфигурация proxy и отдельная сеть сохранены.

## Ещё предстоит

Установка и запуск в эмуляторе не заменяют проверку на физических устройствах.
Пользователь сообщил об отказе установки с общей ошибкой файла приложения;
точный код ошибки на телефоне пока не получен. **Передача голоса,
микрофон, динамик и звонок между двумя телефонами ещё не подтверждены.**
Прохождение звонков через сети мобильных операторов ещё не проверялось.
Фоновый приём в этой версии не реализован: оба приложения должны быть открыты.

Независимый аудит безопасности и нагрузочные испытания не проводились.
Остальные границы версии описаны в README.md и deploy/README_RU.md.
