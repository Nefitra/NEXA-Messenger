Дата: 13 ноября 2026 года.

Файл: `Tonino_0.1.0_test_arm64.apk`, **29 606 789 байт**.
Идентификатор: `com.tonino.secure.test`, версия `0.1.0-test`, код `100`.
Минимальная версия Android 8.0 (API 26), целевая Android 16 (API 36), ABI ARM64.

## Выполнено

| Проверка | Результат |
|---|---|
| `:app:assembleDebug` | APK собран |
| `SecureEngineTest` | 11 тестов пройдены на настоящем libsignal JNI для Linux |
| `RelayIntegrationTest` | 1 тест пройден: два криптографических клиента, HTTP, SQLite, перезапуск relay, ответ и подтверждение доставки |
| Серверные тесты Node | 8 тестов пройдены |
| Robolectric UI и запуск MainActivity | 3 теста пройдены |
| Android Lint | 0 ошибок; остались необязательные рекомендации |
| `apksigner verify` | Подпись APK v2 корректна; это тестовый debug-ключ |
| `zipalign -c -P 16 4` | Проверка пройдена |
| ELF native-библиотек | Все ARM64 LOAD-сегменты имеют выравнивание не менее 16 КиБ |
| Содержимое APK | Только ARM64, тестовая native-библиотека Signal исключена; лицензии включены |
| Конфигурационный скрипт сервера | Секреты согласованы, `.env` приватен, существующие файлы не перезаписываются |
| Исходники | `git diff --cached --check` без замечаний |

Всего **23 автоматизированных теста**: 12 ядра/интеграции, 8 серверных, 3 UI.
Дополнительно выполнены перечисленные проверки сборки и пакета.

Проверены отбрасывание повреждённого шифротекста, подмена публичного ключа и
внешнего ID, повтор сообщения, одновременное начало двух сессий, сообщения
не по порядку, восстановление ratchet после перезапуска и отказ записи на диск.
Проверено, что удалённые одноразовые ключи не восстанавливают первую сессию
из более позднего состояния без её ratchet-записи.

Серверные проверки используют синтетические данные; отдельный интеграционный
тест выполняет настоящее шифрование libsignal и обмен через реальный relay.
Рендеры экранов регистрации и пустого списка чатов просмотрены визуально.

## Ещё предстоит

На физических Android-устройствах APK пока не запускался. **Передача голоса,
микрофон, динамик и звонок между двумя телефонами ещё не подтверждены.**
Не проверялись работа Docker-комплекта на VPS, получение публичного сертификата
и прохождение TURN через сети операторов. Для этого нужны сервер, публичный IP
и DNS-поддомен. Фоновый приём в этой версии не реализован.

Независимый аудит безопасности и нагрузочные испытания не проводились.
Остальные границы версии описаны в README.md и deploy/README_RU.md.
