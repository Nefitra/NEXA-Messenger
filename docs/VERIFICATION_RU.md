# Проверка Tonino Preview 0.1.1

Дата: 14 ноября 2026 года.

Пользователь подтвердил, что первая версия устанавливается и чат работает;
проблема оставалась со звонками. В AndroidManifest отсутствовало разрешение
ACCESS_NETWORK_STATE, необходимое NetworkMonitorAutoDetect библиотеки WebRTC.
Оно добавлено; native WebRTC инициализируется один раз на процесс.

## Границы проверки

VoiceCallIntegrationTest использует настоящие JNI libsignal и WebRTC на Android,
две временные идентичности в памяти, зашифрованную передачу SDP и внешний TURN.
Сигналы передаются между тестовыми участниками в одном процессе; отдельный
HTTP relay в этом Android-тесте не используется. Его доставка и криптографическая
интеграция проверены отдельно. Реальные пользовательские профили не открываются.
Тест получает только краткоживущие TURN credentials, без общего TURN_SECRET
или JOIN_CODE.

Физические микрофоны, разговорный динамик, громкая связь, Bluetooth и сети
мобильных операторов требуют проверки двумя телефонами. В версии 0.1.1 звонки
работают при открытом приложении; при уходе в фон звонок завершается. Push
и фоновый сервис пока не реализованы. Независимый аудит не проводился.
