# Tonino Secure — первая тестовая версия

Отдельное Android-приложение: личные текстовые чаты и голосовые звонки в тёмном
оформлении Tonino с фиолетовыми и голубыми акцентами. Демонстрационные контакты,
имитация ответов, кошелёк, сервисы, геолокация и симулятор Telegram Mini App удалены.
API-ключи AI-сервисов не нужны.

Это **экспериментальная сборка для проверки**, а не прошедший аудит защищённый
мессенджер. Настоящий звонок на двух физических телефонах и работа комплекта
Docker на VPS ещё требуют проверки. Приложение не использует сеть Signal или
Telegram: нужен свой сервер из каталога `server/`.

## Что реализовано

- Локальный профиль без номера телефона и адресной книги.
- Одноразовые приглашения на 24 часа и взаимное добавление контактов. Ключ
  собеседника закрепляется из полученного приглашения; подмена сервером
  отклоняется. Код проверки одинаков на двух устройствах.
- `libsignal 0.107.0`: PQXDH, одноразовые EC/Kyber-ключи и Double Ratchet.
  Заголовок, ID сообщения, адресаты, тип и данные защищены внутри шифротекста.
- История, закрытые ключи, ratchet-состояния и очередь отправки хранятся одним
  зашифрованным AES-GCM файлом в `noBackupFilesDir`. AES-ключ — Android Keystore.
  Состояние фиксируется атомарно до отправки пакета и подтверждения приёма.
- Повторная отправка использует тот же сохранённый пакет. «На сервере» и
  «Доставлено» различаются; доставка подтверждается зашифрованным ответом клиента.
- WebRTC, только аудио. SDP с отпечатками DTLS передаётся через зашифрованный чат.
  ICE собирается целиком, без неаутентифицированного служебного канала.
- TURN включён принудительно; сервер выдаёт временные credentials зарегистрированным
  устройствам. В приложении есть ответ/отбой, отключение микрофона и громкая связь.
- Разрешение микрофона запрашивается при звонке. Скриншоты/запись экрана запрещены
  `FLAG_SECURE`. Автобэкап и перенос данных Android отключены.
- HTTP-сервер с SQLite, проверкой токенов, ограничениями размера/частоты запросов,
  очередью офлайн-доставки и идемпотентными регистрацией/отправкой. HTTP-редиректы
  клиент не принимает, TLS проверяется системными средствами.

## Сборка и проверка

Нужны JDK 21, Android SDK platform 36, Build Tools 35/36, NDK 28.0.13004108 и
Node.js 24+. Node нужен также интеграционному JVM-тесту, который запускает
настоящий HTTP/SQLite relay. Задайте `ANDROID_HOME` или `sdk.dir` в локальном
`local.properties`. Gradle Wrapper 8.13 и контрольная сумма находятся в репозитории.

```bash
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
cd server
npm test
```

Тестовый ARM64 APK: `app/build/outputs/apk/debug/app-debug.apk`. Android 8.0+.
Идентификатор тестовой установки: `com.tonino.secure.test`. Сборка debug и подписана
тестовым Android-ключом; она не предназначена для публикации в Play Store.
Для эмулятора x86_64 собирайте отдельно с `-PtoninoAbi=x86_64`.

Тесты `core/` используют настоящие JNI-библиотеки Signal: подмена ключа,
повтор/повреждение пакета, изменение внешнего ID, одновременный старт сессий,
перезапуск, сообщения не по порядку, ошибка записи на диск и удалённые одноразовые
ключи. Интеграционный тест запускает реальный Node/SQLite relay и проверяет
доставку после его перезапуска. Robolectric проверяет запуск и экранные действия;
он не заменяет проверку APK на физическом Android-устройстве.

## Сервер и два телефона

Пошаговая инструкция: [deploy/README_RU.md](deploy/README_RU.md).
Комплект — Node relay, Caddy HTTPS, coturn; для первого теста достаточно небольшого
отдельного VPS с публичным IPv4. Секреты создаются на самом сервере, их нет в коде.

Без VPS можно проверить интерфейс APK или запустить Node relay на компьютере в
одной локальной сети с телефонами. Debug-клиент допускает HTTP только на явно
локальных адресах (например, `http://192.168.1.10:8080`). Для такого ручного теста
задайте `JOIN_CODE`, `DATABASE_PATH`, `BIND_ADDRESS` и запустите `npm start`.
Для голоса нужен доступный TURN. В release-клиенте разрешён только HTTPS.

## Ограничения этого этапа

- Работа в открытом приложении. При уходе в фон звонок завершается. Push,
  фоновый приём и foreground service для продолжающегося звонка ещё не сделаны.
- Нет восстановления, экспорта закрытых ключей, переноса профиля и нескольких
  устройств. Удаление приложения удаляет историю и ключи.
- Приглашения добавляются вставкой текста. QR отображается, но встроенного
  сканера и обработки ссылок из Android пока нет.
- 16 одноразовых наборов на профиль. Пополнение, ротация подписанного ключа и
  процедура повторной привязки после смены ключа требуют следующего этапа.
  Сервер отказывает при исчерпании набора; перехода к общему статическому ключу нет.
- На устройстве сохраняются последние 500 сообщений, с дополнительным ограничением
  размера истории. Очередь отправки хранится отдельно в том же зашифрованном файле.
- Один сервер, один профиль на устройство; только личный текст и аудио.
- TURN на 3478/UDP или TCP, без TLS/TURN на 443. Ограниченные сети могут блокировать
  звонок. Первые тестовые вызовы следует ограничить 30 минутами.
- Сервер видит IP, адресатов, время и размер обмена; TURN видит сетевые метаданные.
  Гарантии анонимности и независимого аудита не заявляются.
